# Project Instructions

Follow all execution environment policies defined in AGENTS.md. These policies are binding for all code generation, testing, and execution tasks in this repository.

Key requirements:
- **Language preference**: Python first, then R and Bash for bioinformatician workflows
- **Scientific libraries**: Scientific analysis and visualization must use appropriate libraries, such as NumPy, SciPy, Pandas, Matplotlib, Seaborn, Biopython, and Scikit-learn (Python); Bioconductor and CRAN packages (R). Do not substitute Python standard-library implementations to avoid dependencies.
- **Containerization**: Scientific Python, R, and any code requiring additional dependencies must run in Docker with a project Dockerfile and pinned dependency manifest under `code/`
- **Code versioning**: Every generated output uses an 8-character hex code-version identifier in the filename
- **Docker logging**: Capture stdout and stderr from every docker run with hash-matching log file names
- **Directory structure**: Implementation files in `code/`, all data artifacts in `data/`

Before generating code, review the policies in AGENTS.md to ensure compliance with project standards, containerization requirements, and bioinformatician best practices.
